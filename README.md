# Ctrl 自动钓鱼（tidin_autofish）

从「Ctrl 功能菜单」里**单独拆出来的自动钓鱼模组**，只做一件事：服务器自定义钓鱼条的自动收线。

- 客户端模组，纯 Fabric，Minecraft **1.20.1 / 1.20.4**
- 按 **F8** 打开设置页（设置页依赖 **Cloth Config API**）
- 不装 Cloth Config 也能正常钓鱼，只是打不开设置页

## 功能

| 能力 | 说明 |
| --- | --- |
| 绿段判定 | 识别屏幕上的鱼条与指针，指针压到绿色段就按右键收线 |
| 溅水花咬钩 | 屏幕字幕「浮漂：溅起水花」出现时立刻右键咬钩（注入在音效系统里，字幕关掉也有效） |
| 多人游戏检测 | 不依赖客户端浮漂实体是否存在，只凭咬钩音效 + 手持钓竿就按右键；声源半径从 6 格放宽到 16 格。服务器插件常在浮漂实体同步 / 被 clearlag 清理之前就播声，严格等实体会漏按 |
| 速度外推 | 指针速度是**随机**的，按测出来的横向速度把它外推到「这次点击真正生效」的时刻再判定 |
| 自动重抛 | 收线后按设定节奏重抛；只在本次会话识别到过鱼条之后才会重抛，避免盲按 |
| 彩虹条兼容 | 色相分类覆盖 红/橙/黄/绿/青/蓝/紫，服务器的多色鱼条也能识别（命中仍只认绿） |
| 设置项 | 启用开关、溅水花触发、多人游戏检测、收线预判（0~200ms）、重新投掷延迟（500~5000ms）、随机重投延迟（0~100%） |

### 设置项范围

| 项 | 范围 | 默认 | 说明 |
| --- | --- | --- | --- |
| 收线预判 | 0 ~ 200 ms | 40 | 按指针横向速度提前多少点击，见下节 |
| 重新投掷延迟 | **500 ~ 5000 ms** | 1500 | 收线/咬钩之后隔多久再抛竿（原始源码里是写死的 1500ms，这里放开成可调） |
| 随机重投延迟 | 0 ~ 100 % | 0 | 在上面的延迟上叠加随机抖动，打散固定节奏 |

## 构建

```bash
gradle build -Pmc_version=1.20.1     # → build/libs/tidin_autofish-1.0.0+1.20.1.jar
gradle build -Pmc_version=1.20.4     # → build/libs/tidin_autofish-1.0.0+1.20.4.jar
```

不带参数时按 `gradle.properties` 里的 `mc_version`（默认 1.20.4）。

### GitHub Actions

推上去自动跑，两个版本并行；产物在运行页面的 **Artifacts** 里：

- `tidin-autofish-1.20.1`
- `tidin-autofish-1.20.4`

仓库里**没有** `gradlew` / `gradle-wrapper.jar`（二进制不便入库），CI 直接下载官方 Gradle 8.8 分发包。本地要用 wrapper 就跑一次 `gradle wrapper --gradle-version 8.8`。

## 调「收线预判」

这是命中率的关键参数，默认 **40 ms**，范围 0~200。

原理：从「读回画面」到「点击真正生效」有一段延迟（读回 + 判定 + 点击 + 服务端处理）。指针快的时候，等真的看见它进绿段再点，点击落地时它早跑出去了。所以按测出来的横向速度把指针外推到那一刻再判定。

调法：从 0 开始一档档加，加到「该中的都能中」为止；加过头会变成**抢跑点空**（绿段还没到就按下去了）。服务器越远、延迟越高，需要越大。

## 目录

```
src/main/java/cn/blockforge/autofish/
├── AutoFishMod.java          # 入口：F8 开设置页、每刻驱动重抛
├── AutoFishController.java   # 全部钓鱼逻辑：读屏、判定、收线、重抛、配置读写
├── AutoFishSettings.java     # Cloth Config 设置页
└── mixin/
    ├── GameRendererAutoFishMixin.java   # 每渲染帧驱动识别与收线
    └── SoundSystemAutoFishMixin.java    # 监听溅水花音效
```

## 与「Ctrl 功能菜单」的关系

功能是同一个（那份代码里的 `AutoFishController` 原样搬过来，只改了包名），但这里**没有**旋转 / 隐身 / 盘腿坐 / 转R6，也没有对应的 4 个 mixin。

两个模组可以同时装：本模组的自动钓鱼**默认关闭**，不打开就完全不碰右键，不会和别的自动钓鱼模组抢操作。

## 已知限制

- 指针模板贴图是 `assets/tidin_autofish/textures/gui/auto_fish_pointer.png`，如果服务器换了指针皮肤，需要替换这张图
- 绿段判定基于像素阈值，客户端装了光影/大幅改色差的资源包时可能失准
